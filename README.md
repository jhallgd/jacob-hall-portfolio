### 🏛️ Senate Simulation — Civic Education Web Application
A self-initiated, work-based civic technology platform designed to make 
the U.S. legislative process interactive and accessible. Conceived, 
pitched, and built independently — not requested by employer.

**The Problem It Solves:**
Civic education around the legislative process is often passive and 
disengaging. Senate Simulation transforms it into an interactive 
experience where users actively participate in the democratic process.

**What Users Can Do:**
- 🔐 Create accounts and securely log in
- 📜 Review active and historical bills
- 🗳️ Vote on bills in a mock Senate session
- 📊 See voting outcomes and legislative results

**Admin Capabilities:**
- 👤 User management and access control
- 📋 Bill creation, editing, and session management
- 📈 Voting oversight and reporting

**Tech Stack:**
| Layer | Technology |
|---|---|
| Frontend | JavaScript, HTML, CSS |
| Backend | PHP |
| Database | MySQL (SQL) |
| Auth | User authentication & role-based access control |
| Scale | Architected for MySQL maximum row capacity |

**Project Highlights:**
- 💡 Self-initiated — pitched and built without being asked
- 🔄 Continuously developed and iterated
- 🏢 Built in a professional work environment
- 🎯 Transforms complex civic content into engaging UX
